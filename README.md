# Letterboxd Review Extension

A Chrome extension that adds a few quality of life improvements to the Letterboxd review page.
It currently adds the formatting buttons seen on the mobile app (bold, italic, URL) as well as an autosave feature which allows you to take your time writing reviews. Also helpful if Letterboxd goes down (and if you're a constant user, you know it WILL go down) to prevent your review being sent into the void.

## Installation

The extension isn't currently available on the Chrome Web Store, so you'll need to build and install it manually.

### Build

You'll need Node.js and npm (or pnpm) installed.

1. Clone the repository:

   ```bash
   git clone https://github.com/dan-edington/letterboxd-review-extension.git
   cd letterboxd-review-extension
   ```

2. Install dependencies and build:

   ```bash
   npm install
   npm run build
   ```

   This generates the extension files in the `dist` directory.

### Install in Chrome

1. Open Chrome and navigate to `chrome://extensions`.
2. Enable **Developer mode** using the toggle in the top-right corner.
3. Click **Load unpacked**.
4. Select the `dist` directory generated by the build.
5. Open Letterboxd and start writing a review!

### Updating

After making code changes, run `pnpm run build` again, then return to `chrome://extensions` and click **Reload** on the extension. Refresh any open Letterboxd tabs to load the changes.
